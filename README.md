# 실시간 글로벌 날씨 · 미세먼지 대시보드 (`26-w10-weather`)

> 전 세계 기상 및 대기질 데이터를 실시간으로 모니터링하고 시각화하는 인터랙티브 기상 대시보드 웹 애플리케이션입니다.  
> Google DeepMind의 차세대 AI 코딩 에이전트인 **Antigravity IDE**를 활용하여 계획 수립부터 구현, 자체 검증까지 체계적으로 구축되었습니다.

---

## 🌤️ 소개

본 프로젝트는 **Open-Meteo 글로벌 오픈 기상 API**를 기반으로 전 세계 도시의 실시간 기상 관측 데이터와 환경부 기준 미세먼지 등급을 한눈에 파악할 수 있는 모던 대시보드입니다.

### 🌟 주요 핵심 기능
- **실시간 날씨 카드**: 현재 기온, 체감 온도, 습도, 풍속, 강수량 및 WMO 표준 기상 상태별 Lucide 동적 아이콘 매핑
- **한국 환경부 기준 대기질 카드**: PM10(미세먼지), PM2.5(초미세먼지) 수치, 4단계 등급 뱃지(좋음/보통/나쁨/매우 나쁨) 및 진행 바 시각화
- **24시간 기온 미니 SVG 차트**: 당일 시간대별 기온 변화를 순수 SVG 꺾은선 및 그라데이션 영역으로 가볍고 부드럽게 렌더링
- **7일간 주간 일기예보**: 향후 일주일간의 요일, 날씨 아이콘, 강수 확률(%), 상대적 최고/최저 기온 범위 막대 바 제공
- **400ms 디바운스 적용 도시 검색**: Open-Meteo Geocoding API를 연동하여 전 세계 도시명을 검색하고 드롭다운으로 즉시 선택
- **라이트 / 다크모드 시스템**: 사용자의 가독성을 위해 **라이트모드를 기본값**으로 제공하며, 원클릭 토글 스위치 및 `localStorage` 유지 지원
- **기상 상태 연동 동적 비주얼 테마**: 맑음, 흐림, 비, 눈, 뇌우 및 주야간(`is_day`)에 따라 대시보드 전체 배경 그라데이션이 0.8초 부드럽게 전환
- **인터랙티브 세계 날씨 맵 (지구본 모드)**: SVG 세계지도 모달에서 대륙별 주요 국가 핀을 클릭하여 실시간 현지 날씨를 미리보고 대시보드로 원클릭 이동
- **최근 본 도시 (즐겨찾기)**: 최근 검색하거나 조회한 도시를 `localStorage`에 자동 보관하여 상단 칩을 통해 원클릭 복귀

## 🤖 어떻게 만들었나요 (Antigravity IDE 경험)

- **Copilot과의 차이점 (Agentic Workflow)**:
  - 기존의 Copilot이 개발자가 코드를 작성할 때 다음 줄을 제안하는 인라인 보완 도구였다면, Antigravity IDE는 전체 프로젝트 요구사항을 분석하여 아키텍처 설계와 구현 전략을 스스로 수립하는 **자율형 코딩 에이전트(Autonomous Agent)**의 면모를 보여주었습니다.
- **Implementation Plan(구현 계획)의 가치**:
  - AI가 코드를 바로 작성하지 않고, 먼저 Mermaid 아키텍처 다이어그램과 세부 컴포넌트 변경 계획, 보안 검토 사항이 담긴 **Implementation Plan**을 작성하여 개발자의 승인을 요청했습니다. 이를 통해 개발 의도와 기술적 방향성을 사전에 조율할 수 있어 코드의 신뢰도와 안정성이 극대화되었습니다.
- **자체 기능 검증(Walkthrough)의 체계성**:
  - 구현 완료 후 정적 코드 린트(`oxlint`)와 프로덕션 빌드(`vite build`)를 자체 실행하여 결함이 없음을 스스로 확인하고, 결과 보고서(Walkthrough)를 생성하여 변경 내역을 명확히 증명하는 프로세스가 매우 인상적이었습니다.

## 🌐 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

- **Open-Meteo API의 특징**:
  - 비상업적 이용이 가능한 완전 공개(Public) 기상 데이터 API입니다.
  - 번거로운 API Key 발급 절차나 과금 등록 없이 HTTPS 엔드포인트를 통해 실시간 날씨, 시간별 예보, 주간 예보, 대기질, 지오코딩 데이터를 신속하게 제공합니다.
- **UI 컴포넌트와 API 통신 로직(`src/api/weather.js`) 분리 이유 (Decoupling)**:
  - **관심사의 분리(Separation of Concerns)** 원칙에 따라 UI 렌더링 계층과 네트워크 데이터 계층을 철저히 격리했습니다.
  - API 엔드포인트나 파라미터 규격이 바뀌더라도 `src/api/weather.js`만 수정하면 되며, 컴포넌트는 오직 데이터 객체에만 집중할 수 있어 코드 재사용성과 유지보수성이 크게 향상됩니다.
- **도시 검색 시 디바운스(Debounce, 400ms)의 필요성**:
  - 사용자가 검색창에 "Tokyo"를 입력할 때 한 글자 타이핑마다 즉각 API를 호출하면 불과 몇 초 사이에 수많은 HTTP 요청이 발생합니다.
  - 이는 클라이언트 측 리소스 낭비는 물론 서버에 불필요한 DoS(서비스 거부)성 부하를 유발하며, API 제공자로부터 `429 Too Many Requests` 상태 코드로 IP가 차단될 수 있습니다.
  - **400ms 타이머 기반 디바운스**를 적용하여 사용자의 연속 타이핑이 멈춘 시점에만 1회 요청하도록 네트워크 트래픽을 최적화했습니다.

## 🛡️ 보안에서 확인한 것 (사이버보안과 체크포인트)

### 1. Public API vs Private/Secret API (키 분리와 백엔드 프록시의 필요성)
- Open-Meteo는 API Key가 필요 없는 완전 공개 API이므로 브라우저(React 클라이언트)에서 직접 호출해도 보안상 안전합니다.
- 하지만 결제 모듈, 사내 인사정보, 과금이 발생하는 유료 지도 API처럼 **비밀 키(Secret Key)**가 필요한 API는 절대 프론트엔드 코드에 포함해서는 안 됩니다.

### 2. 프론트엔드에서 Secret Key를 직접 호출할 때 발생하는 보안 사고
- 브라우저 개발자 도구의 **Network 탭**이나 빌드된 자바스크립트 번들 파일(정적 소스코드)을 열람하면 프론트엔드에 하드코딩되거나 번들된 키는 100% 탈취당합니다.
- 악의적인 공격자가 이 키를 탈취해 무단 API 호출로 거액의 과금 폭탄을 유발하거나, 사내 데이터베이스를 유출하는 치명적인 보안 사고가 일어납니다.
- **해결책 (BFF 아키텍처)**: 반드시 **BFF(Backend For Frontend) 또는 백엔드 프록시 서버**를 구축하여 비밀 키를 서버의 안전한 환경변수(`.env`)로 보호하고, 프론트엔드는 백엔드 프록시와만 통신하도록 설계해야 합니다.

### 3. Mixed Content (혼합 콘텐츠)와 HTTPS 암호화 통신
- 배포된 사이트가 `https://` 보안 프로토콜을 사용할 때, 안전하지 않은 `http://` API 엔드포인트를 호출하면 브라우저 보안 엔진에 의해 통신이 강제 차단됩니다(Mixed Content 방어).
- HTTP 통신은 평문으로 전송되어 중간자 공격(MITM)에 의해 데이터가 도청되거나 악성 스크립트로 위조될 위험이 있습니다. 따라서 모든 외부 통신은 종단간 암호화(TLS/SSL)가 적용된 HTTPS 엔드포인트를 엄수해야 합니다.

## 🎨 커스터마이징한 부분

1. **라이트 / 다크모드 지원 (기본값: 라이트 모드)**
   - 헤더 상단에 슬라이딩 애니메이션이 적용된 모드 토글 스위치([`ThemeToggle.jsx`](./src/components/ThemeToggle.jsx))를 제작했습니다.
   - 첫 접속 시 깨끗하고 화사한 라이트 모드로 시작하며, 다크 모드 전환 시 세련된 글래스모피즘 네이비 톤으로 반전되고 브라우저 `localStorage`에 영구 보관됩니다.

2. **기상 상태 및 주야간 연동 스마트 비주얼 테마 엔진**
   - [`src/utils/weatherThemes.js`](./src/utils/weatherThemes.js) 모듈을 통해 WMO 기상 코드와 낮/밤 지표(`is_day`)를 실시간 분석합니다.
   - 맑음(주간/야간), 흐림, 비, 눈, 뇌우, 안개 등 현재 날씨에 어울리는 최적의 그라데이션 및 래디얼 앰비언트 패턴이 대시보드 전체 배경에 `0.8초` 동안 은은하게 스며들도록 연출했습니다.

3. **인터랙티브 세계 날씨 맵 (지구본 모드)**
   - [`src/components/WorldMapModal.jsx`](./src/components/WorldMapModal.jsx)를 통해 외부 무거운 3D 라이브러리 없이 순수 SVG 벡터 좌표 변환 알고리즘으로 세계지도와 전 세계 주요 국가(한국, 일본, 미국, 영국, 프랑스, 호주, 브라질 등)의 핀포인트 펄스(Pulse) 애니메이션을 구현했습니다.
   - 핀을 클릭하면 비동기로 현지 기상 데이터(기온, 체감온도, 습도, 풍속)를 팝업으로 미리보고, 원클릭으로 해당 국가의 대시보드로 즉시 전환됩니다.

4. **최근 본 도시 / 즐겨찾기 바**
   - 사용자가 검색하거나 선택한 도시를 `localStorage`에 최대 5개까지 중복 없이 자동 저장([`RecentCities.jsx`](./src/components/RecentCities.jsx))하여 상단 칩을 통해 클릭 한 번으로 다시 볼 수 있도록 사용자 경험(UX)을 극대화했습니다.
